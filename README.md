# AI可視化辦公室 · visual-office

Cozy Swedish-light 3D office (walnut furniture + neon accents) + dashboard for Morris Desk Grok Bot specialists.

**Live:** https://morriscsy.github.io/visual-office/

## v0.4
- Walnut-style desks, chairs, shelves, pantry accents (warm wood on a bright Swedish base)
- Subtle cyan / magenta / amber neon cove strips + logo highlight
- Bot chats use **EconPulse** calendar / Actuals / tape / daily-radio topics (`topics.json` + offline fallback)
- Each specialist speaks in its own voice (macro, tape, strategy, chart patterns, notes, …)
- Preserves v0.3.1 mobile fixes (100dvh / ResizeObserver / collapsed feed sheet / header in-flow)

## Views
- **3D辦公室** — Three.js rooms, walking staff (toilet / pantry / EconPulse chat)
